# Umrah & Hajj Companion (رفيق العمرة والحج) — application mobile

Application Expo (SDK 57) avec expo-router. Voir le [README principal](../README.md).

```bash
yarn install
yarn start       # serveur de développement Expo
yarn typecheck   # vérification TypeScript
yarn lint        # ESLint
yarn test        # tests unitaires Jest
```
