# بطاقة متجر Play · العربية (ar)

## اسم التطبيق (30 حرفاً كحد أقصى)

```
رفيق العمرة والحج
```

## الوصف المختصر (80 حرفاً كحد أقصى)

```
دليل العمرة والحج خطوة بخطوة مع الأدعية وأوقات الصلاة واتجاه القبلة
```

## الوصف الكامل (4000 حرف كحد أقصى)

```
رفيق العمرة والحج يرافق المعتمرين والحجاج خطوة بخطوة، باللغة العربية والفرنسية والإنجليزية.

دليل العمرة
الإحرام والتلبية ودخول المسجد الحرام والطواف ومقام إبراهيم والسعي والتقصير: كل مرحلة مشروحة بأسلوب بسيط مع أحكامها ونصائح عملية.

دليل الحج
الحج يوماً بيوم من الثامن إلى الثالث عشر من ذي الحجة: أنواع النسك (التمتع والقران والإفراد)، ومنى، وعرفة، ومزدلفة، ورمي الجمرات، والهدي، والحلق، وطواف الإفاضة، وأيام التشريق، وطواف الوداع.

أدعية كل مرحلة
لكل موقف من المناسك: النص العربي مشكولاً، مع النطق والترجمة وعدد مرات التكرار. واستمع إلى التسجيلات المتاحة حتى دون اتصال بالإنترنت.

عدّاد الأشواط
احسب أشواط الطواف والسعي بلمسة واحدة، مع اهتزاز عند كل شوط ودعاء اللحظة على الشاشة.

أوقات الصلاة والتنبيهات
أوقات الصلاة في مكانك، والصلاة القادمة، وتنبيه عند دخول وقت كل صلاة أو قبله بدقائق.

القبلة والميقات
اتجاه القبلة ببوصلة الهاتف، وأقرب ميقات حسب موقعك.

الأماكن المقدسة
خريطة تفاعلية لأماكن مكة المكرمة والمدينة المنورة، مع الاتجاهات إلى كل مكان وأرقام الطوارئ.

وأيضاً
• قائمة تجهيز السفر حتى لا تنسى شيئاً (الوثائق، الإحرام، الصحة، الحج)
• مجموعة أدعية لكل موقف
• رسائل عملية تُنشر خلال الموسم
• الوضع الليلي وتكبير الخط
• يعمل دون إنترنت في الأساسيات

التطبيق مجاني، ويعرض إعلانات صغيرة لا تظهر أبداً أثناء المناسك (الدليل، العدّاد، الأدعية، القبلة).

هذا التطبيق أداة مساعدة: لكل مسألة شرعية، ارجع إلى أهل العلم الموثوقين.
```

## ملاحظات الإصدار 1.3.0 (500 حرف كحد أقصى)

```
جديد: الحج يوماً بيوم من ٨ إلى ١٣ ذي الحجة، مع أدعية كل مرحلة.
• اسم جديد وأيقونة جديدة: رفيق العمرة والحج
• أدعية كل مرحلة من العمرة مع الاستماع
• عدّاد أشواط الطواف والسعي
• تنبيهات أوقات الصلاة
• خريطة الأماكن المقدسة وأرقام الطوارئ
• قائمة تجهيز السفر، تحسين القبلة، الوضع الليلي
```
